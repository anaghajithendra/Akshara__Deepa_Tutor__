# Akshara-Deepa Tutor 📚

Akshara-Deepa Tutor is an Android-based self-learning educational application developed for 10th standard students. The app helps students improve learning through chapter-wise quizzes, progress tracking, mastery analysis, and study score monitoring.

---

## 📌 Features

- Home Dashboard
- Mission Map
- Chapter-wise Learning
- Quiz System
- Progress Tracking
- Strength & Weakness Analysis
- Study Score Monitoring
- Daily Learning Streak
- Simple and Interactive UI

---

## 🛠 Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- MVVM Architecture
- Room Database
- StateFlow
- Material 3 UI
